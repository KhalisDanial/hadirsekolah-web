# 🏫 HadirSekolah Admin Dashboard

Sistem pengurusan kehadiran berasaskan awan (cloud) yang direka khas untuk memudahkan pentadbir sekolah mengurus data murid, kakitangan (Guru/AKP), dan memantau kehadiran secara real-time menggunakan teknologi **Supabase**.

![Versi](https://img.shields.io/badge/version-1.0.0-blue.svg)
![Supabase](https://img.shields.io/badge/Backend-Supabase-green.svg)
![JavaScript](https://img.shields.io/badge/Language-JavaScript-yellow.svg)

## ✨ Ciri-Ciri Utama

- **📊 Dashboard Real-Time**: Pantau statistik kehadiran murid dan staf secara langsung tanpa perlu menyegarkan (refresh) halaman.
- **👥 Pengurusan Data Berpusat**: Tambah, kemas kini, dan padam maklumat murid serta kakitangan dengan mudah.
- **📥 Mass Import (CSV)**: Pindahkan data beratus murid atau staf dalam masa beberapa saat menggunakan fungsi import CSV.
- **📷 Pratinjau Gambar Profil**: Muat naik dan lihat gambar profil murid/staf terus melalui sistem.
- **📄 Eksport Laporan**: Jana laporan kehadiran dalam format **PDF** dan **Excel (CSV)** untuk tujuan rekod rasmi.
- **📱 Responsif**: Antaramuka moden yang bersih dan mesra pengguna, sesuai untuk paparan desktop dan tablet.

## 🚀 Teknologi Yang Digunakan

- **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid), Vanilla JavaScript (ES6+).
- **Backend-as-a-Service**: [Supabase](https://supabase.com/) (Auth, Database, Realtime, Storage).
- **Pustaka Luaran**:
  - [FontAwesome](https://fontawesome.com/) - Ikonografi.
  - [jsPDF](https://github.com/parallax/jsPDF) - Penjanaan laporan PDF.
  - [SheetJS](https://sheetjs.com/) - Pemprosesan fail Excel/CSV.
